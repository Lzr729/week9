# Week 10 交接说明

Week10的首要任务是研读一篇VC/PE论文，拆解研究问题、理论机制、样本与识别、变量测量、缺失处理、稳健性和解释边界。

随后将论文方法与Week9的32变量、变量可用性、公司画像和候选组合逐项映射，形成“保留 / 修订 / 新增 / 删除”建议，再决定是否需要数据补充或版本升级。

代表性公司选择在此之后进行。选择依据必须是明确研究问题、案例角色与纳入排除规则；不得只按融资金额、单项轴值或S6互补分值作自动排名。

建议Week10闸门：

1. 论文研读卡字段完整；
2. 方法可迁移性逐项说明；
3. 变量差距有证据；
4. 选择标准可复核；
5. 决策记录为 GO / REVISE / HOLD。
